## 1. 월간 전체 순서

사이드바 번호가 곧 권장 순서다. 화살표는 **반드시 먼저 끝나야 하는** 선행이다.

```
1 수임처 리스트
        │
        ▼
2 공단 EDI 병렬  ── 또는 ──  3 건강보험 / 4 국민연금 / 5 고용보험 (단독)
        │
        ▼
6 급여자료입력  (공단 자료를 위하고 엑셀에 반영)
        │
        ├──────────────► 7 급여명세 PDF
        │
        ▼
8 원천이행상황 마감 ──────────────────────────────► 10 지방소득세 납부서 마감
        │                                                │
        ▼                                                ▼
9 원천전자신고 (.01)                              11 지방전자신고 (.1 / .2)
        │                                                │
        ▼                                                ▼
12 홈택스 파일변환신고                            13 위택스 회계파일신고
```

| 선행 | 후행 | 이유 |
|------|------|------|
| 1 | 나머지 전부 | 수임처·사업자번호·신고주기가 있어야 한다 |
| 2~5 (또는 2) | 6 | 공단 PDF/엑셀이 있어야 보험료 컬럼을 덮어쓴다. 없어도 6번은 위하고 엑셀만으로 진행되지만 공단 금액은 안 들어간다 |
| 6 | 7, 8 | 급여가 반영된 뒤 명세·원천 마감 |
| 8 마감 | 9 | 원천이행을 마감해야 전자신고 데이터가 생긴다 |
| 9 | 12 | 홈택스에 올릴 `.01` 파일 |
| 10 마감 | 11 | 납부서를 마감해야 지방 전자신고 데이터가 생긴다 |
| 11 | 13 | 위택스에 올릴 `.1`/`.2` 파일 |

반기 수임처는 **8번·10번을 6월·12월에만** 마감한다. 그 외 월은 원천·지방 마감을 하지 않는다.

## 2. 공통 규칙

### 2.1 로그인

프로그램과 사람 모두 **포털 로그인을 자동화하지 않는다.** Chrome이 해당 사이트 로그인 화면을 열면 공동인증서(또는 간편인증)로 직접 로그인한다. 한 번 로그인한 창에서 수임처만 바꿔 가며 반복한다. 수임처마다 다시 로그인하지 않는다.

| 포털 | 주소 | 인증서 |
|------|------|--------|
| WEHAGO | https://www.wehago.com/ | 공동인증서. 메인에 **나의 수임처**가 보이면 완료 |
| 국민건강보험 EDI | https://edi.nhis.or.kr/ | 업무대행(법인) 공동인증서 |
| 국민연금 EDI | https://edi.nps.or.kr/ | 업무대행 공동인증서. 화면이 Nexacro로 바뀌면 완료 |
| 근로복지공단 | https://total.comwel.or.kr/ | **사무대행 `151-86-01316`** 공동인증서. **로그아웃**이 보이면 완료 |
| 홈택스 | https://www.hometax.go.kr/ | 공동인증서/간편인증. **로그아웃**이 보이면 완료 |
| 위택스 | https://www.wetax.go.kr/main.do | **전자세금용** 공인인증서. 일반 인증서와 구분 |

### 2.2 사업장관리번호

공단 세 사이트는 수임처를 **사업장관리번호**로 찾는다.

1. 사업자등록번호에서 하이픈을 뺀다. `515-86-01709` → `5158601709`
2. 끝에 `0`을 붙인다. → `51586017090`
3. **지점·추가사업장**은 끝자리가 `1`, `2`, … 일 수 있다. 표에 적힌 관리번호가 있으면 그걸 쓰고, 자동 `+0`을 쓰지 않는다.

검색 결과가 여러 행이면 **관리번호 숫자가 완전히 같은 행만** 고른다. 첫 행을 무조건 누르면 다른 사업장 자료를 받게 된다.

### 2.3 저장 위치

바탕화면이 막혀 있으면 내 문서 → 홈 → `%LOCALAPPDATA%` → TEMP 순으로 같은 폴더 구조를 만든다. 수임처명 공백은 `_`로 바꾼다.

단독 실행:

```
바탕화면\국민건강보험_{YYYYMM}\{수임처}\
바탕화면\국민연금_{YYYYMM}\{수임처}\
바탕화면\고용보험_{YYYYMM}\{수임처}\
바탕화면\위하고급여자료입력_{YYYYMM}\{수임처}\
바탕화면\위하고급여명세PDF_{YYYYMM}\{수임처}\
바탕화면\원천전자신고_{YYYYMM}\{수임처}\
바탕화면\지방소득세전자신고_{YYYYMM}\{수임처}\
```

2번 병렬만 최상위가 다르다.

```
바탕화면\공단EDI_{YYYYMM}\{수임처}\국민건강보험\
바탕화면\공단EDI_{YYYYMM}\{수임처}\국민연금\
바탕화면\공단EDI_{YYYYMM}\{수임처}\고용보험\
```

6번은 단독 폴더를 먼저 보고, 없으면 병렬 폴더에서 공단 자료를 찾는다.

### 2.4 프로그램 dry-run 체크박스와 사람 작업의 대응

GUI 상단 **dry-run**은 기본 켜짐이다. 사람이 따라 할 때는 아래만 구분하면 된다.

| 메뉴 | dry-run ON (기본) | 사람이 “자동화와 같게” 하려면 |
|------|-------------------|------------------------------|
| 6 급여자료입력 | **삭제후 업로드**에서 취소 → 서버에 반영 안 됨 | 실제 반영하려면 확인을 눌러 업로드 |
| 12 홈택스 | **전자파일 제출하기** 직전에서 멈춤 | 실제 접수하려면 제출하기 + 확인 2회 |
| 나머지 | 영향 없음 | 프로그램이 하는 대로 진행 (마감·파일 제작·위택스 제출 포함) |

13번 위택스는 dry-run과 무관하게 **오류가 없으면 제출까지** 한다.

### 2.5 WEHAGO 공통 (6~11번)

1. https://www.wehago.com/#/main 로그인.
2. **AI 에디션**, **2차 인증** 안내는 닫는다. **비과세** 모달은 **취소**. **수당 및 공제등록**은 닫기.
3. 메인 검색창에 **사업자등록번호**를 타이핑하고 **Enter**. (붙여넣기만 하면 필터가 안 먹을 수 있다.)
4. 카드의 퀵버튼 **급여**를 눌러 SmartA로 들어간다.
5. 8~11번은 사이드바 **급여자료입력(SWSA0101)**을 한 번 눌러 화면을 연 뒤, 목적 메뉴로 이동한다.
6. 다음 수임처: SmartA에서 나와 메인으로 돌아가 3번부터. 위하고 재로그인은 하지 않는다.

전자신고(9·11)는 PC에 **WehagoNTS**가 설치되어 있어야 파일이 저장된다.

## 3. 1. 수임처 리스트 확보

**사이트:** WEHAGO 수임처관리  
**주소:** https://www.wehago.com/tedge/#/taxagent  
**산출물:** 프로그램 DB (수임처명, 사업자등록번호, 신고주기). 파일 없음.

### 수임처 목록을 사람이 모을 때

1. WEHAGO 로그인 후 위 주소로 이동한다.
2. 떠 있는 모달을 모두 닫는다.
3. (선택) 검색란에 **담당자 이름**을 넣고 Enter → **조회**. 비우면 전체.
4. 왼쪽 수임처 카드 목록을 **끝까지 스크롤**해 카드를 전부 불러온다.
5. 카드를 하나씩 클릭한다.
6. 상세에서 **사업자등록번호** `XXX-XX-XXXXX`를 적는다.
7. 카드 태그에서 **매월** / **반기**를 적는다.
   - `테스트1,원천,매월`처럼 콤마로 나뉘면 그 값.
   - 태그가 붙어 있으면 글자 안에 매월·반기가 있는지 본다.
   - **매월과 반기가 동시에 보이면 비워 둔다.** 나중에 8번 화면에서 확인한다.
8. 이름 앞 `[테스트] `는 뺀다.

프로그램의 **새로 가져오기**가 위와 같다. 목록이 비었거나 빠진 수임처가 있으면 이 절차를 다시 한다.

## 4. 2. 공단 EDI 병렬 자동화

한 메뉴가 아니라 **3·4·5를 세 Chrome에서 동시에** 도는 묶음이다. 사람이 동일하게 하려면 창 세 개를 열고, **로그인은 한 사이트씩** 끝낸 뒤 수임처 루프만 동시에 한다.

### 준비 (한 창씩)

1. 대상 **연도·월**을 정한다.
2. Chrome 창 1: https://edi.nps.or.kr/ → 4번 SOP대로 로그인.
3. Chrome 창 2: https://edi.nhis.or.kr/ → 3번 SOP대로 로그인.
4. Chrome 창 3: https://total.comwel.or.kr/ → 5번 SOP대로 로그인. 인증서는 사무대행 `151-86-01316`.
5. 한 사이트 로그인이 실패하면 그 사이트의 수임처 작업을 시작하지 않는다. 프로그램도 다음 창을 열지 않는다.

프로그램은 위 순서로 창을 띄운다. 처음부터 세 사이트에 동시에 로그인하지 않는다.

### 업무

로그인이 끝나면 각 창에서 **같은 수임처 목록**을 3·4·5 SOP대로 처리한다. 저장만 병렬 폴더를 쓴다.

```
바탕화면\공단EDI_{YYYYMM}\{수임처}\국민건강보험\
바탕화면\공단EDI_{YYYYMM}\{수임처}\국민연금\
바탕화면\공단EDI_{YYYYMM}\{수임처}\고용보험\
```

**고용보험은 5번 GUI 단독과 범위가 다르다.** 병렬(및 CLI)은 산재·고용 **당월보험료 부과내역**까지 받는다. 아래 [5번](#7-5-고용보험-edi)의 “병렬일 때 추가 문서”를 따른다.

## 5. 3. 국민건강보험 EDI

**사이트:** 국민건강보험 EDI  
**주소:** https://edi.nhis.or.kr/  
**산출물:** `가입자고지내역서_건강_{YYYYMM}.pdf` **만** (엑셀 없음)

단독: `바탕화면\국민건강보험_{YYYYMM}\{수임처}\`  
병렬: `바탕화면\공단EDI_{YYYYMM}\{수임처}\국민건강보험\`

### 로그인 후 한 번

1. 보안모듈·공지처럼 `edi.nhis.or.kr`가 아닌 팝업 탭은 닫는다.
2. 메인에 **수임사업장선택**이 보일 때까지 기다린다.

### 수임처 1건

1. 화면에 이전 수임 사업자명이 남아 있으면 **로그인 사업장 돌아가기**를 누른다.
2. **수임사업장선택** → 팝업.
3. 검색 구분 **사업장관리번호**, 검색어에 관리번호 → 조회.
4. 표에서 관리번호가 **숫자까지 같은 행**의 사업장명을 클릭한다. 없으면 구분을 **사업장명**으로 바꿔 수임처명으로 재검색.
5. 팝업을 닫고, 메인에 표시된 이름이 방금 고른 곳인지 확인한다. 다르면 그 건은 중단한다.
6. **받은문서** 클릭 → 웹EDI 새 탭.
7. 진행상태 라디오 **전체**. (신규·열람이 아님)
8. 서식명 콤보에서 정확히 **가입자 고지(산출) 내역서**.
9. 목록에서 **고지년월 = 대상 YYYYMM** 인 행. 같은 월이 여러 장이면 **목록 맨 위**. **2차를 고르지 않는다.** (2차 우선은 국민연금만)
10. 그 행의 서식명 칸을 **더블클릭**.
11. 상단 **인쇄** → Crownix 미리보기 → **PDF 저장**.
12. 파일명을 `가입자고지내역서_건강_{YYYYMM}.pdf`로 바꾼다. 찌꺼기 파일은 지운다.
13. 미리보기·웹EDI 탭을 닫고, 메인에서 **로그인 사업장 돌아가기**.

해당 월 문서가 없으면 그 수임처는 스킵한다.

### 다음 수임처

재로그인하지 않는다. 메인으로 돌아온 뒤 1번부터.

## 6. 4. 국민연금 EDI

**사이트:** 국민연금 EDI  
**주소:** https://edi.nps.or.kr/  
**산출물:**

| 파일 | 용도 |
|------|------|
| `결정내역통보서_{YYYYMM}.xlsx` | 6번 급여자료 원천 (가입자+소급+국고가 **한 장**) |
| `결정내역통보서_{YYYYMM}_출력.pdf` | 열람용 |

단독: `바탕화면\국민연금_{YYYYMM}\{수임처}\`  
병렬: `바탕화면\공단EDI_{YYYYMM}\{수임처}\국민연금\`

### 로그인 후, 그리고 메뉴 이동 전마다

**직원 사칭 관련 유의사항** 등이 뜨면 **오늘 하루 그만보기**를 체크하고 제목줄 **X**로 닫는다. 사업장전환·출력 창은 닫지 않는다.

### 수임처 1건

1. 헤더 **사업장전환**. (안 되면 메뉴 **업무대행서비스 → 위탁사업장**)
2. 검색구분 콤보를 **매번 사업장관리번호**로 바꾼다. 화면 글자에 “사업장명”과 “사업장관리번호”가 같이 보여도, 기본값은 사업장명인 경우가 많다.
3. 관리번호를 넣고 검색.
4. 결과에서 관리번호 **완전일치** 행의 사업장명을 **더블클릭**. 첫 행 금지. 없으면 사업장명으로 재검색.
5. 상단 **결정내역** → **국민연금보험료 결정내역**.
6. **조회**.
7. 내용 칸에서 `{연도}.{월}` (예: `2026.06`)
   - **1순위: 같은 달 + 「2차」**
   - **2순위: 같은 달의 첫 행**
   - 그 달이 없으면 **스킵**. 다른 달 첫 행으로 가지 않는다.
8. 해당 행을 **더블클릭**. 탭 **최종결정내역**이 보이면 상세 진입.
9. **최종결정내역** 탭에서 **통합저장**.
10. 출력옵션 **주민번호 전체표출** → 확인. 엑셀 저장.
11. 상단 **출력** → 다시 **전체표출** → 확인.
12. Crownix 미리보기에서 보이는 PDF 아이콘은 **인쇄**이므로 쓰지 않는다. **저장 → PDF 파일로 저장**.
13. 미리보기 탭·남은 모달을 닫는다.

가입자내역 / 소급분내역 / 국고지원내역을 **탭마다 따로 받지 않는다.** 예전 방식이지만 현재 자동(및 이 SOP)은 통합저장 한 장이다.

엑셀이 있어야 그 수임처를 완료로 본다. PDF만 실패하고 엑셀이 있으면 6번 반영은 가능하다.

## 8. 6. WEHAGO 급여자료입력

**메뉴:** SmartA 사이드바 **급여자료입력** (`SWSA0101`)  
**저장:** `바탕화면\위하고급여자료입력_{YYYYMM}\{수임처}\`  
**선행:** 1번. 공단 2~5가 있으면 보험료를 덮어쓴다.

### 수임처 1건

1. [2.5](#25-wehago-공통-611번)대로 해당 수임처 **급여** 진입.
2. 사이드바 **급여자료입력**.
3. **간이세액** 개정 안내가 있으면 닫는다.
4. 검색영역 **귀속연월**을 대상 `YYYY.MM`으로 맞춘다.
5. 구분 드롭다운 **급여+상여**.
6. **지급일**이 자동으로 채워졌는지 확인한다. 비어 있으면 구분을 다시 **급여+상여**. 지급일을 임의로 넣지 않는다.
7. **복사후 재계산** 모달이 뜨면 **복사후 재계산** → 다음 모달은 **취소**.
8. 왼쪽 사원 그리드 **전체 선택**.
9. **재계산** → **고용보험 재계산** 체크 → **확인** → “전체사원의 자료를 재계산” **확인**.  
   “재계산할 사원이 없습니다”여도 확인 후 계속.
10. 우측 수집 메뉴 → **엑셀 내려받기**. 원본을 수임처 폴더에 둔다.
11. 엑셀을 업로드 양식으로 고친다.
    - 2행 헤더를 1행으로 평탄화, **합계** 행 삭제
    - 사원코드는 자릿수를 맞추지 말고 그대로
    - [16절](#16-급여자료-엑셀-반영-규칙)대로 공단 금액을 사원명으로 덮어쓴다
    - 파일명 예: `{원본}_업로드.xlsx`
12. 화면 버튼이 **해제**이면 이미 급여 마감 → **엑셀 업로드를 하지 않는다.**
13. 미마감이면 수집 메뉴 → **엑셀 불러오기** → 업로드 파일 선택.
14. **사원코드연결**이 뜨면 **변환** → “연결되지 않은 사원 및 연말 입력된 사원은 제외하고 변환됩니다” **확인**.
15. **제개산**이 뜨면 **취소**.
16. 미리보기에서 헤더 **행 1** 선택 → **② 엑셀제목설정** → **확인** → **확인**.
17. 확인(`#confirm`).
18. “연결되지 않은 사원” **확인**.
19. **삭제후 업로드**
    - 프로그램 dry-run ON: **취소** (서버 미반영)
    - 실제 반영: **확인** (기존 급여를 지우고 올린다)

## 10. 8. WEHAGO 원천이행상황신고서

**메뉴:** **원천징수이행상황신고서** (`SWTA0101`)  
**비밀번호 없음. 파일 없음.** 항상 실제 마감/재마감.  
**권장 선행:** 6번. **반기는 6월·12월만.**

### 수임처 1건

1. 급여 진입 → 사이드바 **급여자료입력** 한 번 (화면 초기화) → **원천징수이행상황신고서**.
2. 신고유형 라디오는 **읽기만** 한다. 클릭하지 않는다. 점이 반기에 있으면 반기, 아니면 매월. (DB에 매월/반기가 있으면 그걸 우선)
3. **귀속기간·지급기간**
   - 매월: 대상 연월 ~ 같은 연월
   - 반기, GUI 월이 6월: 당해 **01~06**
   - 반기, GUI 월이 12월: 당해 **07~12**
   - 반기인데 그 외 월: **마감하지 않고 종료**
4. 주기를 화면에서도 DB에서도 못 정하면 **중단**. 매월로 추측해 단월 마감하지 않는다.
5. **조회**.
6. “저장된 내용을 불러오시겠습니까?” 같은 **확인/취소**는 반드시 **취소**. 확인을 누르면 옛 마감 자료가 다시 올라와 이번 달 급여가 반영되지 않는다.

8. 이미 **마감해제**(이미 마감된 상태)이면:
   1. **마감해제** → 확인
   2. 버튼이 **마감**인지 확인
   3. 같은 기간으로 **재조회** (다시 **취소**)
   4. **재마감**

어느 단계에서 버튼 문구가 예상과 다르면 그 수임처는 실패로 두고 화면을 직접 본다.

**비밀번호:** **영문 소문자 + 숫자** (이후 13번 위택스와 **같은 값**)  
**산출물:** `바탕화면\지방소득세전자신고_{YYYYMM}\{수임처}\` 아래 **`.1` 또는 `.2`**

흐름은 9번과 같다. 메뉴만 `SWER0109`, 저장 폴더만 `지방소득세전자신고_{YYYYMM}`이다.

1. 급여 → 급여자료입력 → **지방소득세특별징수전자신고**.
2. 지급기간 → 수임처 코드도움 확인 → **제작(F4)** → 변환파일 비밀번호 → **전자신고 파일 제작(Enter)**.
3. WehagoNTS에서 해당 수임처 폴더 선택 → 덮어쓰기 예.

코드상 반기 6·12 스킵은 없다. 10번을 비신고월에 안 했으므로 그달 파일은 비는 것이 정상이다.

## 14. 12. 홈택스 원천세 신고

**사이트:** 홈택스  
**주소:** https://www.hometax.go.kr/  
**메뉴:** **원천세 신고 > 일반신고 > 파일변환신고**  
**선행:** 9번의 `.01`  
**비밀번호:** 9번에서 파일에 건 값

파일 위치: `바탕화면\원천전자신고_{YYYYMM}\{수임처}\` 중 **가장 최근 `*.01`**.

홈택스는 약 24분 비활동 시 연장 안내, 30분 시 로그아웃이다. 프로그램 GUI는 세션 연장을 켜지 않으므로, 다건이 길면 사람이 **로그인 연장**을 눌러야 할 수 있다.

### 수임처 1건

1. **원천세 신고 > 일반신고**.
2. **파일변환신고**. 진입 알림은 **확인**.
3. 해당 수임처 `.01` 파일을 선택해 올린다.
4. **파일검증하기**. “이미 검증이 완료된 자료가 존재합니다. 다시 하시겠습니까?”면 **확인**.
5. **비밀번호입력** 팝업에 파일 비밀번호 → **확인**.
6. **제출하러 가기**. **전자파일 제출하기**가 보이면 제출 화면이다.

여기까지가 프로그램 **dry-run ON(기본)** 과 같다.

### 실제 접수 (dry-run을 끈 자동화와 동일)

7. **전자파일 제출하기**.
8. “정상 변환된 신고서를 제출합니다” **확인**.
9. “신고서를 제출하시겠습니까?” **확인**.
10. **원천세 신고서 접수증**을 확인하고 닫는다. 같은 과세기간을 다시 내면 **대체**(최신 접수 1건만 유효).

변환결과 정상/오류는 화면을 사람이 본다. 프로그램은 검증 그리드를 신뢰하지 않고 제출을 시도할 수 있다. 접수 후 **신고내역 조회**에서 접수번호·일시를 확인한다.

### 다음 수임처

같은 로그인으로 파일변환신고 화면으로 돌아가 다음 `.01`.

## 15. 13. 위택스 지방세 신고

**사이트:** 위택스  
**주소:** https://www.wetax.go.kr/main.do  
**화면:** **신고 → 특별징수 → 회계파일신고** (특별징수 회계파일신고)  
**직접 주소:** https://www.wetax.go.kr/etr/lit/b0701/B070101M31.do  
**선행:** 11번의 `.1` 또는 `.2`  
**비밀번호:** 11번 파일 비밀번호  
**휴대전화:** 신고 담당자 번호. 모든 수임처에 **같은 번호**를 다시 넣는다.

프로그램은 dry-run과 무관하게, 서식검증 **오류 0 · 정상 1건 이상**이면 제출까지 한다. 사람이 “자동화와 같게” 하려면 오류가 없을 때 **제출하기**를 누른다.

### 세션 시작

1. 메인 이벤트 팝업 **닫기**. 로그인 후에도 다시 뜨면 한 번 더 닫는다.
2. **전자세금용** 공인인증서로 로그인.
3. **신고 → 특별징수 → 회계파일신고**.

### 수임처 1건

1. **휴대전화번호**만 입력. 유선 전화번호는 건드리지 않는다.
2. **파일비밀번호**.
3. **암호화 파일선택** — `바탕화면\지방소득세전자신고_{YYYYMM}\{수임처}\` 최신 `.1` 또는 `.2`. 엑셀·메모는 무시.
4. **파일변환하기**. “업로드 하신 회계 파일의 신고정보를 검증하시겠습니까?” **확인**.
5. 서식검증 화면에서 **정상 신고 내역** / **오류 신고 내역** 건수 확인.
   - 오류 > 0 또는 정상 < 1 → **제출하지 않는다.** 11번 파일을 고쳐서 다시.
   - 통과하면 **제출하기** → “제출 하시겠습니까?” **확인**.
6. 제출결과(일괄신고·제출처리)를 본 뒤, **업로드 화면으로 돌아간다.** 입력칸이 비어 보일 수 있다. 다음 건을 위해 정상이다.

### 다음 수임처

업로드 화면에서 휴대전화·비밀번호를 **다시 넣고** 파일만 바꾼다.

끝난 뒤 위택스 **일괄신고목록**에서 접수 결과를 사람이 확인한다.

## 16. 급여자료 엑셀 반영 규칙

6번 11단계에서 사람이 엑셀에 넣는 값. 프로그램은 사원명(공백 무시)으로 맞춘다. 이름이 다르면 그 직원은 위하고 값이 그대로 남는다.

### 원천 파일 (단독 폴더 우선, 없으면 병렬 `공단EDI_…`)

| 기관 | 파일 |
|------|------|
| 건강보험 | `가입자고지내역서_건강_{YYYYMM}.pdf` |
| 국민연금 | `결정내역통보서_{YYYYMM}.xlsx` (통합). 없으면 구버전 `가입자내역_엑셀` / `소급분내역_엑셀` / `국고지원내역_엑셀` |
| 고용보험 | `고용보험료지원금정보_{YYYYMM}.xls` — Page1 실업급여지원금(근로자), Page2 환수금(근로자) |

### 컬럼

| 위하고 컬럼 | 넣는 값 |
|-------------|---------|
| 건강보험 | 고지내역서 **산출** 건강보험료 |
| 장기요양보험료 (요양보험, 장기요양) | **산출** 요양보험료 |
| 건강보험정산 / 건강보험료정산 | 정산금액. **사유가 퇴직이면 제외**. 연말정산 전용 컬럼이 없으면 정산 + 연말정산 + 이자 합산 |
| 장기요양보험정산 | 요양도 같은 규칙 |
| 연말정산(건강보험) 등이 **따로** 있으면 | 그 컬럼에 연말+이자만. **퇴직정산은 자동으로 넣지 않음** (담당자가 수동) |
| 국민연금 | 당월 근로자 본인기여금 − **국고지원 본인몫** |
| 국민연금정산 (국민연금 소급분) | 소급분 본인기여금. 이 컬럼이 없으면 국민연금에 더함 |
| 고용보험 | **재계산으로 받은 셀 값** − \|실업급여지원금\| + \|환수금\|. 조정 금액이 0이면 재계산값을 유지 |

국고지원: 통합엑셀은 이미 본인몫. 구버전 국고지원내역 파일은 전액의 절반을 본인몫으로 본다.

고용보험 기본 0.9%는 위하고 **재계산**이 채워 둔다. 지원금·환수금만 가감한다. 재계산값을 지우고 조정분만 넣으면 안 된다.
